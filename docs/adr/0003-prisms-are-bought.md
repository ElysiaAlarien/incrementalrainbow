# Prisms are bought with money

Prisms are bought during a run by spending money, at a price that goes up with each prism and never resets across runs. Most incremental games give the prestige currency automatically from a formula on progress, without taking anything away. We chose a purchase so that each prism is a real trade-off against growing the current run ("buy a prism or build a factory"). Do not change this to an automatic grant on prestige without revisiting this decision.
