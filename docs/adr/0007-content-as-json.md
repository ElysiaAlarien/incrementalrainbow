# Content is JSON data in `data/`

Colors, symbols, recipes, and balance values load from JSON files in `data/`, not from code. Later content (markets, transport tiers, research, demand events, and prestige upgrades) goes there too. `Content` reads and validates the files and reports every problem as text instead of failing hard. The simulation gets its content at construction, so tests build small content of their own. We chose JSON over Godot `.tres` resources because it is engine-neutral, easy to diff and review, and easy to build in tests. Values that are not balanced yet are marked as placeholders in the file.
